## 0. このルールの思想（2026/10/14 全面改訂）― **遮断ではなく、確度の見積もり**

> **本人の言葉:**
> 「OKLOも選択としては間違いじゃなく、**勝負に出た故の負け**。
> 必要なのは数値をみて**遮断**することじゃなくて、数値をみて**判断材料**にできること。
> メタトレンドとしての妥当性。数値を見て判断材料を得て。**買うか買わないかの確率を出す**イメージ。
> **絶対勝つ勝負は個別株じゃなくて積み立てでやってる**から、個別株は違う視点が必要かも」

### 🔴 旧ルールの構造的な誤り

§9の 3-2〜3-13 は **すべて「ゲート（合否判定）」として作られていた。**
1つでも落ちたら買わない。**結果、2026年10月の時点で検討した約15銘柄すべてが「見送り」になった。**

**これはルールが機能した証拠ではなく、ルールが役割を間違えている可能性のほうが高い。**

### 🔑 「本物のメタトレンド」の判定基準（2026/10/14 新設）

**「構造変化か」を感覚で言わない。次のどれかで説明できるか。**

| 根拠 | 意味 | 実例 |
|---|---|---|
| **物理** | **選択ではなく、物理法則が決めている** | **データセンターの液冷。空気と水の体積比熱は約3,500倍差。<br>熱量6倍（20→120kW）でファン動力は3乗の216倍。空冷は技術ではなく物理で詰む** |
| **制度** | 規制・法改正が需要を作る／殺す | 中国のレアアース輸出規制／FDAのコンパウンド規制 |
| **不可逆性** | 一度入れたら戻らない。買い替えではなく構造需要 | **液冷の配管・CDU・800VDC配電はDCの構造に入る** |

- **どれも書けないなら、それは「流行」であって「構造変化」ではない**（Peloton型）
- ⚠ **職能で判断できる領域（電力・モータ・インバータ・産業機器）は、市場平均より良く判断できる。
  §1-2は人的資本を"リスク"としてのみ扱っているが、"判断の優位"でもある。両面で扱う**

### 📋 どのルールが「遮断」で、どれが「材料」か

**遮断として残すもの（これだけは通らなければ買わない）**

| ルール | 理由 |
|---|---|
| **§1-2 勤務先との相関** | **法的・倫理的制約。例外なし** |
| **§1 最低ポジション 30,000円** | 判断コストに見合わない（RXRX 5,262円の前例） |
| **§1 サイズ上限** | **賭けが致命傷にならないための設計。§11で確度連動に改訂** |
| **3-10 問1「方向」** | **構造変化か一時的ショックか。** 無いものは賭けですらない（Peloton型） |
| **3-10 問2「器」** | **優位が"存在しうるか"**。※「独占が完成しているか」ではない。<br>Zoom（Microsoftが無料で束ねた）・Beyond Meat（委託製造）は**優位が消えた/無い**ので❌。<br>**Tesla 2019・OKLOのSMR技術は「優位が存在しうる」ので✅。完成度は確度で測る** |
| ※ **3-10 問3「時計」は遮断しない** | **時計が鳴っていない＝確度「低」に落とすだけ**（§11）。**ここがOKLOの扱いを変えた核心** |
| **3-6 / 3-7 / 3-12** | **遮断ルールではなく「材料の精度管理」。** 数字が間違っていたら確度も間違う |
| **§3 強制再評価トリガー** | **検証の起動義務。OKLOの本当の失敗はここ** |

**判断材料に変えるもの（落ちても買える。確度が下がるだけ）**

| ルール | 新しい使い方 |
|---|---|
| 3-2 純度 | **テーマが当たったとき、どれだけ取れるかの係数** |
| 3-3 不足／独占／累積中／コモディティ | **優位が持続する年数の推定** |
| 3-4 利益率 | **堀の強さの証拠**（独占の裏付け） |
| 3-5 シェアの方向 | **確度の更新**（増加＝上げ、減少＝下げ） |
| 3-8 粗利率の反転 | 同上 |
| 3-9 数量×FCF/純利益×累積優位 | 同上 |
| 3-11 想定リターン | **リターンの推定**（確度とは別の軸） |

## 1-2. 勤務先との相関ルール（TMEIC）

勤務先は **TMEIC（東芝三菱電機産業システム）**。2003年に東芝と三菱電機の折半出資で設立され、
現在も **三菱電機の関係会社かつ東芝インフラシステムズの関係会社**。

### 売買対象外（親会社・関係会社）

| 銘柄 | 理由 |
|------|------|
| **三菱電機 (6503)** | 親会社。インサイダー取引防止規程の対象と推定 |
| **東芝 (6502)** | 親会社（東芝インフラシステムズ経由）。同上 |

### 購入前に内規確認が必要

日立 (6501)、富士電機 (6504)、明電舎 (6508)、安川電機 (6506) などの競合他社。
競合他社株は通常インサイダー規制の対象外だが、TMEICの内規で
「重要な取引先リスト」に含まれる可能性があるため、**購入前にインサイダー取引防止規程を確認する**。

### 人的資本との相関

TMEICの大容量ドライブ・PVパワーコンディショナは、データセンター建設と電力インフラ増強で
需要が伸びる。**雇用そのものがAI×電力テーマにレバレッジされている。**
同テーマへの投資は収入と資産を同じマクロ要因に乗せるため、**産業・電力枠は合計5%を上限**とする。

> OKLOは2026年4月時点で4%だった。この上限があれば損失は半分で済んでいた。

## 2. 利確ルール（2026/10/12 改訂 ―― **銘柄のタイプで分岐させる**）

**改訂理由**: 旧ルール「サテライトは+100%で半分売却」は **§3「価格は売却理由にしない」と正面衝突**し、
さらに **§9 3-9（累積優位＝売るほど強くなる会社）を買う方針と矛盾**していた。
**AMDが+193.85%で未執行だったのは、守るとどちらかのルールを破るため。**

### 判定: まず §9 3-9(3)【累積優位】があるかを見る

> **累積優位の判定**: 1単位売ったとき、**次の1単位を有利にする資産が自社に残るか**

| タイプ | 利確ルール | 理由 |
|---|---|---|
| **累積優位あり**<br>（AMD・NVIDIA型） | **価格では売らない。**<br>§3のメタトレンド評価のみで判断 | **複利で積み上がる会社を機械的に半分売ると、一番効く銘柄を一番早く半分にする。**<br>NVIDIA・Teslaは+100%で半分売っていたらリターンの大半を失っていた |
| **累積優位なし**<br>（テーマ株・模倣可能・一過性） | **+100%で半分売却**（旧ルールのまま）<br>原資は現金かコアへ。同じ銘柄に戻さない | 伸び続ける根拠がないので、利益は確定させる |
| コアのインデックス投信 | 適用しない | ― |

### 両方に残すもの

- **§3の「-50%到達＝強制再評価トリガー」は、累積優位の有無にかかわらず適用する**
- これはOKLOを-4%から-56%まで一度も検証しなかった失敗への対策なので、外さない
- **「累積優位あり」は保持の理由にはなるが、検証しない理由にはならない**

### ⚠ 旧ルールが存在した理由（消さずに残す）

> 2026年4〜8月、**AMD/MRAM/ARMの +97,442円の含み益を放置して戻した**（本ファイル冒頭）

**「累積優位あり」を言い訳に全部放置すると、この失敗が復活する。**
だから累積優位の判定は**四半期レビューで毎回書き直す**こと。一度「あり」と書いたら永久ではない。

### 記録: 2026/10/12 の判定

| 銘柄 | 含み益 | 累積優位 | 判定 |
|---|---|---|---|
| **AMD** | **+193.85%**（95,400円） | **あり** ― Zenの設計資産、サーバーへの採用実績が積み上がる | **保持**。価格では売らない。<br>次回四半期レビューで累積優位を再確認する |

## 2-2. 買い増しのルール

**「下がったら買う」には2つの条件を課す。両方を満たした時だけ買い増す。**

### 条件① 上限枠に収まるか（計算する）

その銘柄が属する枠（§1）の上限内に、買い増し後のポジションが収まること。
株価が下がると保有分の評価額も総資産も下がるため、**買える株数は単純な割り算では出ない**。

```
n株保有後の比率 ≦ 上限  を解く:

  n × P / (総資産 - 現在の保有評価額 + n × P) ≦ 上限比率

  P: 買い増し時の1株あたり価格（円）
  n: 買い増し後の合計株数
```

> 例（GEV / 2026年9月16日時点）: 総資産4,201,423円、1株139,598円(3.32%)、産業・電力枠の上限5%
> → 2株が収まるのは **1株104,149円（約$653）以下**。現在値$875.22から **-25.4%**
> → それまでは**ルール上2株目は買えない**（総資産が約5,584,000円まで増えても収まる）

### 条件①-2 【為替】円建ての上限は為替で動く（2026/10/8 追加）

**条件①の計算は円建てで行うが、外貨建て銘柄の円換算値は為替で動く。**
企業が何も変わらなくても、**円高になれば枠に収まり、円安になれば収まらなくなる**。

```
外貨建て銘柄が上限に収まる為替 = 上限金額（円） ÷ 株価（外貨）
```

> **例: ASML $1,400（予想PER32倍の水準）／ 4%上限 176,821円**
> → 収まる為替は **126.3円/$**（2026/10時点の157.06円から -19.6%）
>
> **到達経路は3つ**
> | | 条件 |
> |---|---|
> | ① | 総資産が **5,497,100円** に増える（為替157円のまま） |
> | ② | 円が **126.3円** まで高くなる（総資産そのまま） |
> | **③** | **その組み合わせ** ← 現実的にはこれ |
>
> | 為替 | 必要な総資産 |
> |---|---|
> | 149円 | 5,222,350円（今 +80万円） |
> | **141円** | **4,947,250円（今 +53万円）** |
> | 134円 | 4,672,500円（今 +25万円） |
>
> **円高と資産増加は、同じゴールに両側から働く。** 為替157円固定で計算すると過度に悲観的になる。

**検討のたびに、その時点の為替で枠を再計算すること。** 為替は `iGrow` のトップに表示される。

### 条件② 下落の理由が「降りる条件」に該当しないこと

購入時に書いた降りる条件（§3）を**必ず照合してから**買う。

**⚠ 為替要因を必ず分離すること（2026/10/8 追加）**

外貨建て銘柄と日本株では、円高の意味が**正反対**になる。

```
米株:   円高  →  円建て価格が下がる  →  **企業の中身は変わらない**  →  純粋に仕入れ値が下がる
日本株: 円高  →  株価が下がる        →  **企業の利益も実際に減る**    →  安くなった理由がある
```

これは「AMATの-36.2%＝シェア喪失」と「KLAの-39.8%＝調整」の区別と同じ構造。
**円高局面の日本株はAMAT側、米株はKLA側。**

> ⚠ **三菱重工（2027年1月に判断予定）はGTCCの海外受注が利益の柱で輸出比率が高い。**
> 円高局面で株価が下がっていたら、「割安になった」のか
> 「円高で利益見通しが下がった」のかを**必ず分離してから**判断すること。

| 下落の理由 | 行動 |
|-----------|------|
| 降りる条件のいずれかに該当 | **売却**（買い増しではない） |
| **円高による外貨建て銘柄の円換算下落** | **買い増し可**（企業の中身は変わっていない） |
| **円高による日本の輸出企業の下落** | **降りる条件として扱う**（利益が実際に減る） |
| どれにも該当しない（需給、市場全体の調整、セクターローテーション） | **買い増し可** |

**同じ-25%でも意味が正反対になる。** 下落幅そのものは判断材料ではない。

### なぜこの形か

**下落中の買い増しは、OKLOの失敗の鏡像になり得る。**
OKLOは-4%から-56%まで、一度も前提を検証されないまま保有が続いた。
下落局面で「安くなった」を理由に買い増せば、検証しないまま**ポジションが膨らむ**分だけ悪化する。

条件①は**サイズの暴走**を止め、条件②は**検証の省略**を止める。

### 記録: GEV 2株目の買い増し条件（2026年9月16日設定）

- ① 株価 **$653以下**
- ② かつ、下落理由が降りる条件4つ（Electrificationのマージン低下／ガスのバックログ縮小／
  Windの損失侵食／州規制の本格化）の**いずれにも該当しない**
- ③ 期限は設けない。枠が空くまで待つだけなので機会損失が発生しない

### 🔴 【2026/10/20 改訂】現金は配分目標を持たない ―― **比率管理から実額管理へ**

**旧ルールの「現金25%」は廃止。** 生活防衛資金を**実額で固定**し、それを超えた分はすべて配分対象とする。

```
生活防衛資金 = 800,000円（実額・固定。比率では持たない）
```

**算定根拠（2026/10/20）**

| 項目 | 金額 | 出典 |
|---|---|---|
| 二人以上・勤労者世帯・**世帯主40歳未満**の消費支出 | **301,216円/月** | 家計調査年報 2025年平均（総務省統計局） |

| ＋ 実際の家賃（会社補助後） | 40,000円 | 本人申告 |
| **= 月の生活費** | **約320,000円** | |
| **× 2.5ヶ月** | **800,000円** | **本人決定（2026/10/20）** |

> ⚠ **家賃の扱いを間違えないこと。** 家計調査の「住居」18,678円は持ち家世帯を含み、
> **住宅ローンの元本返済は消費支出に含まれない。** だから「家賃4万は平均より安い」と
> 単純に引き算すると逆方向に間違える。**実際には統計の住居項目より高い。**

**なぜ比率をやめるのか**

| | 比率25%で持つ | **実額80万で固定** |
|---|---|---|
| 今日（総資産 4,443,155円） | 1,110,789円 | **800,000円（18.0%）** |

| 1年後 +250万（6,943,155円） | 1,735,789円 | **800,000円（11.5%）** ← 差 **+935,789円** |

> **生活費は資産が増えても増えない。だから防衛資金は実額で固定するのが正しい。**
> **比率で持つと、資産が増えるほど「投資に回らない現金」が自動的に増える。**
> 現金比率は何もしなくても 18.0% → 15.3% → 11.5% と下がる。
> **Bodie-Crane(1997)の「25〜44歳はCash 7%」には、売らずに時間だけで近づく。**

> それでも画面は +11.2ポイント改善する。**

**Bessembinder(2018): 生涯でT-billに勝つ銘柄は42.6%、中央値はマイナス**（§32）。
**負ける銘柄のほうが多い分布で、負けた銘柄だけが画面から消える仕組みを使えば、
ダッシュボードは構造的に実態より良く見える。しかも売れば売るほど良く見える。**

**→ `realized_ledger.md` に記録する。**

| いつ | 何を書くか |
|---|---|
| **売却を決めた時点（約定前）** | 🔴 **取得価額・評価損益・売却理由・判定日**。**約定後では取得価額が画面から消える** |
| 約定後 | 売却日・売却額・**売却日の株価**・**売却日のオルカン基準価額**・口座区分 |
| 四半期レビュー | 売却済み銘柄の**その後の株価**を1行追記（「売って正解だったか」の検証） |
| 年1回 | 入金総額を更新し、**真の成績**を計算 |

**原則**
1. **実現損は消さない。** 金額が小さくても残す
2. **成績を語るときは、画面の評価損益ではなく `総資産 − 入金総額` を使う。**
   画面の評価損益は保有中の銘柄だけなので成績ではない
3. **売却後も追跡をやめない。** やめると §3「テーマが死んだら売却」が正しかったか検証できなくなる

## 8. ルールの例外を作る場合

上限やルールを意図的に破る判断はあり得る。ただし**必ず理由を記録する。**

- どのルールを、なぜ破るのか
- 想定している最大損失額
- どうなったら元に戻すのか

**理由が残っていないと、次に同じことをした時に検証できない。**

   - ⚠ **【指標の混在に注意／2026/10/12】3-4は営業利益率、3-8・3-9は粗利率。数字が近いので必ず混同する**

     - **Infineon**: 提供元が19.61〜23.2倍 → 会社ガイダンス（売上€16.3B×セグメント利益率20%）から

     **外部の予想PERは「桁の当たりをつける」用途に限り、判断には使わない。**
   - **どちらも「安いから買い」という結論を一度書いてしまった。** 価格の判断は推奨の土台なので、
     ここを間違えると分析全体が崩れる。**数字の出所の確認は、分析そのものより優先する**
   - ⚠ **【2026/10/12 明確化】3-6は「予想PERの数字を間違えるな」というルールであり、
     「予想PERが○倍を超えたら買うな」ではない。合否の基準は 3-11 を使う。**
     32倍という数字には根拠が無かった（4%枠から逆算した副産物だった）。**取得の正確さと合否の基準は別**
3-7. **【分母を確認する】成長率は分母の取り方で別物になる。**
   - **買収・事業売却があった会社の成長率は、そのままでは比較できない**
   - 確認すること
     - 前年の数字は**継続事業ベースか、売却前の総額か**
     - 買収分はいくらか（会社が開示していることが多い）
     - 自分が計算したオーガニック成長率が、**会社やアナリストの説明と桁で合っているか**

     - 正しい値: ex-Ansys $1,765.7M ÷ **前年の継続事業 $1,650.8M** = **+7.0%**

       事業を売った分だけ「減収」に見え、**Cadence(+24%)との差を過大に評価した**
     - 実際のQ4ガイダンスはex-Ansysで**約+15%**。会社は「EDAは2桁成長に加速」と説明していた
   - **「見かけの成長 − 買収分」だけでは足りない。売却分も戻さないと同じ土俵にならない。**
3-5. **【シェアの方向】シェアの水準ではなく増減を見る。**
   - Arista: データセンターEthernetスイッチで首位だったが、NVIDIAが2年で4%→21.5%と逆転（2026 Q1）
   - AMAT: 高値から-36.2%＝**シェア喪失**／ KLA: 高値から-39.8%＝**シェアは増加中**
   - **同じ下落率でも意味が正反対。株価の下げ幅は企業の情報を一切含まない**
3-8. **【独占がない銘柄を買う場合】CEOではなく「粗利率の反転」で入る。**（2026/10/11 追加・判例検証済み）

   **なぜこのルールが必要になったか**
   - 本人の提案: 「独占してたらその分野でいけると思うけど、**独占してないというのは割安を掴むチャンス**とも言える。
     ただ危険なので、その時は**CEOのキャラクター**を大事にしたい。イーロン・マスクのような
     バックキャスト思考で科学や工学をわかってる、大風呂敷を広げる人が良い」
   - 問題意識は正しい。**3-3（不足か独占か）と 3-4（利益率で検算）は、すでに独占が完成した会社しか通さない。**
     ブレイク前の会社は構造的に全部落ちる。だから「落ちた会社をどう拾うか」の基準が別に必要になった。
   - そこで**今のルールで過去の大化け株が拾えたのかを逆算で検証した。** 以下はその結果。

   **【検証】現行ルールでの過去銘柄の判定**

   | 銘柄 | 起点 | 当時の粗利率 | 現行ルールの判定 | その後 |
   |---|---|---|---|---|
   | **NVIDIA** | FY2016 | **56.1%** | ✅ **通過**（ASML 54%・KLA 62.5%と同格） | 取れた。当時データセンターは売上の約11% |
   | **Tesla** | 2019 | **16.6%** | ❌ 3-3・3-4・3-6 **全滅**（赤字でPER計算不能） | **約20倍。取り逃し** |
   | **AMD** | 2014/10 Su就任 | 33.4%→27.1%→**23.2%**（下降） | ❌ 落ちる | **約48倍。取り逃し**（概算・二次情報） |
   | **AMD** | 2017 Zen出荷後 | 23.2%→**34.0%**（**反転**） | △ 3-4は通る | 反転後に入っても**十数倍は取れた** |
   | **Intel** | 2021 Gelsinger就任 | 低下中（下記） | ❌ 落ちる | **CEO解任（2024/12）** |

   **【判例1】CEOの技術力は入口の基準にできない ―― 1勝1敗で、負けが −56%**
   - 数字が全部落ちていて**CEOだけが根拠だったケースは2件**。その成績が **1勝1敗**。
     - マスク（工学の学位なし／Tesla）→ ✅ 約20倍
     - **ジェイコブ・デウィット（MIT原子核工学PhD／OKLO）→ ❌ −56%**
   - **技術的な資格は、より高い学位を持つ側が負けている。** これで「技術がわかるCEO」は単独の買い基準にならない
   - さらに逆向きの判例: **ティム・クック（産業工学＋MBA、オペレーション出身／技術者ではない）**
     → Apple 時価総額 約3,500億ドル → **約4.95兆ドル**。**技術者でなくても勝てる**

   **【判例2】技術理解が効くのは「ボトルネックが技術である場合」だけ**

   | 会社 | ボトルネック | CEOの型 | 結果 |
   |---|---|---|---|
   | NVIDIA | **技術**（CUDA／GPUアーキ） | ジェンスン・フアン（スタンフォードMSEE、チップ設計者） | ✅ |
   | AMD | **技術**（Zenアーキテクチャ） | **リサ・スー（MIT電気工学PhD、半導体デバイス研究者）** | ✅ |
   | Tesla | **量産**（生産地獄） | マスク（工学の学位なし／製造に執着） | ✅ |
   | Apple | **サプライチェーン** | クック（オペレーション） | ✅ |
   | **OKLO** | **規制**（NRC認可） | デウィット（原子核工学PhD） | ❌ **PhDは規制に効かなかった** |
   | **Intel** | **技術 → だが時間が無かった**（判例3） | **ゲルシンガー（486設計者・元Intel CTO）** | ❌ |

## 11. 確度とサイズ（2026/10/14 新設）― **低確度でも買える。ただし小さく**

### 確度の3段階

**①メタトレンド3問（§9 3-10）をすべて通ったものだけが対象。** そのうえで確度を分ける。

| 確度 | 条件 | **サイズ上限** | **強制再評価** |
|---|---|---|---|
| **高** | 3問すべて✅ **かつ 独占の証拠が営業利益率に出ている**（3-4で45%超など） | **4%**（176,821円） | −50% |
| **中** | 3問✅ だが**独占は未完成**。3-8（粗利率の反転）か 3-9（累積優位）で説明できる | **2%**（88,410円） | **−40%** |
| **低** | **方向は✅ だが「時計」が鳴っていない**（売上ゼロ／規制待ち／量産前） | **1%**（44,205円） | **−30%** |

> **⚠ 確度が低いほど、再評価トリガーを浅くする。**
> **小さいポジションほど放置されやすい。それがOKLOで起きたこと**（−4%から−56%まで無検証）。

### 🔄 確度は動く ―― これが一番大事

**確度は買った時点で固定ではない。四半期レビュー（`review_sheet.md`）で毎回書き直す。**

| 変化 | 行動 |
|---|---|
| **時計が鳴った**（売上が立った／認証が下りた） | **低 → 中**。**買い増せる** |
| **独占が利益率に出た**（営業利益率が45%超へ） | **中 → 高**。**買い増せる** |
| **シェアの方向が下向きに変わった**（3-5） | **高 → 中 → 低**。**降りる検討** |
| **テーマ（方向）が死んだ** | **即売却**（§3） |

> **OKLOに当てはめると:** 買った時点で確度「低」（売上ゼロ・認証待ち）→ **サイズ1%が正解**。
> そして**GEVの受注残$176Bが判明した時点で「時計が鳴らない」ことが確定** → **そこで降りるべきだった**。
> 実際には4%で持ち、−56%まで放置した。**サイズと検証、両方が外れていた。**

### 📊 期待値の考え方

**勝率ではなく期待値で見る。** 確度「低」は外れる前提で組む。

```
確度「低」1%で10倍になったら   → 総資産 +9%
確度「低」1%で−56%になったら  → 総資産 −0.56%

→ 10回に1回当たれば釣り合う。
→ これがサテライトの設計思想。コアでは絶対にやらない。
```

**だから「見送り」の判定は、本来もっと少なくていい。**
**2026年10月時点で検討15銘柄すべてが見送りになったのは、ルールの設計がおかしかったから。**

### ⚖️ 旧ルールとの関係

- 変わるのは**使い方だけ**: 「1つでも落ちたら買わない」→「落ちた数だけ確度が下がる」
- **3-6・3-7・3-12（数字の精度管理）は引き続き遮断ルール。**
  **材料が間違っていたら、確度の見積もりも間違う**

## 12. 将来の価値に対して割安か（2026/10/14 新設）― **「今の数字に対する割安」を探すのをやめる**

> **本人の言葉:**
> 「**数値だけでみれば相場はその通りに動いてるから妥当の値段になってるに決まってる。**
> **割安を探すのではなくて、メタトレンドとして、企業として将来の価値が上がる勝ち目を判断して、
> 将来の株価に対して割安かが大事**」

### 🔴 旧3-11が原理的に無意味だった理由

3-11は「**今の数字を将来に延長して、今の株価と比べる**」計算だった。
**だが市場も同じ数字を見て同じ延長をしている。だから差がつかない。**

**優位が生まれるのは「市場が織り込んでいない将来」を見つけたときだけ。**

### ① まず「市場が何を織り込んでいるか」を逆算する

**会社目標どおりに達成した場合、今の株価では年率何%になるか**を計算する。

| 銘柄 | 会社目標どおりのシナリオ | 年率 | 市場は何を織り込んでいるか |
|---|---|---|---|
| **Vertiv** | 2030 $26B×27%・株数−7%・終端20倍 | **+5.9%** | **会社目標を割り引いている。目標超過に賭ける余地あり** |
| **KLA** | 2030 EPS$8.40（目標中央）・終端28倍 | **+4.7%** | 同上。ただし会社目標がEPSレンジで上限まで織り込み済み（§26） |
| **ASML** | 2030 €52B（目標中央）・終端30倍 | **−2.8%** | **既に「目標の上限以上」を織り込んでいる。ズレの余地が小さい** |

> **年率が低いほど、市場は「会社目標を超えること」を前提にしている。**
> **マイナスなら、目標どおりでは報われない＝超過が織り込み済み。**

### ② 【必要終端PER法】― これが一番効く

```
必要終端PER = 今の株価 × (1 + ハードル12%)^4 ÷ 2030年EPS
```

**これを「今のPER」と比べる。**

| 銘柄 | **今のPER** | 2030年EPS | EPS倍率 | **必要終端PER** | **倍率の余裕** | 前提 |
|---|---|---|---|---|---|---|
| **Vertiv** | 36.2倍 | $15.25 | **2.28x** | **25.1倍** | **−30.9%** | **✅ 倍率が3割下がっても12%を達成できる** |
| **KLA** | 36.1倍 | $8.40 | 1.55x | **36.6倍** | +1.3% | 🟡 **倍率維持が前提** |
| **ASML** | 約40倍 | （概算） | 1.19x | **52.9倍** | **+32.1%** | ❌ **倍率がさらに上がる前提。最も危険** |

> **読み方**
> - **必要 < 今** → 倍率が下がっても達成できる。**余裕がある**
> - **必要 ≈ 今** → **倍率維持が前提**
> - **必要 > 今** → **倍率上昇が前提。最も危険**
>
> **なぜVertivが有利か: EPSの成長率が違う。**
> **Vertiv $6.70 → $15.25（年率22.8%）／ KLA $5.41 → $8.40（年率11.6%）**
> **成長が速いほど、倍率が下がっても吸収できる。これが「将来の価値に対する割安」の正体。**

### ③ そのうえで「メタトレンドが正しければ、どこがズレるか」を1行書く

**①②は市場の前提を測っただけ。優位はここから出る。**

- **ズレを説明できなければ買わない。**「安いから買う」は無し
- **例（Vertiv）**: 市場は2030年$26B（CAGR20-22%）を見ている。
  **だがラック密度は 20kW→120kW→250kW と動いており、1ラックあたりの冷却設備の金額が上がる。
  台数成長とは別の軸。$26Bが「今の密度の延長」なら保守的すぎる可能性**（`watchlist.md` §27）
- **例（ASML）**: 市場は既に目標上限以上を織り込んでいる。**ズレを作るには「会社目標の外」が要る**

### ④ 外れ方も書く

**「何が起きたら間違いだったと分かるか」を、買う前に書く。**
（例・Vertiv: 密度の上昇が止まる／NVIDIA認定が広く出てコモディティ化／Schneiderが買収で逆転）

### ⚠ 3-11との関係

- **3-11の「終端PER×目標業績」という計算自体は使う。** 捨てるのは**使い方**
- **❌ 旧: 計算結果を「ハードルに届くか」の合否判定に使う**
- **✅ 新: 計算結果から「市場が何を織り込んでいるか」を逆算し、ズレを探す材料にする**
- **3-11の2026/10/14改訂（メタトレンドが効く変数を固定しない／目標の与えられ方で余地が違う）はそのまま有効**

### 🔴 矛盾① §2（+100%で半分売却）と §3（価格は売却理由にしない）が正面衝突 ―― **決着済み**

| | 内容 |
|---|---|
| **§2 利確ルール** | 「サテライト銘柄が **+100%** に達したら **半分売却**。例外はコアのインデックス投信のみ」 |
| **§3 降りるルール** | 「米国個別株は**価格ルールではなくメタトレンド評価**で判断する。**価格は売却理由にしない**」 |

- **米国個別株のサテライトは両方の対象**になるため、逃げ道がない
- **実害が出ている: AMDが +193.85% で、§2なら半分売却済みのはずが未執行。**
  ルールが守られていないのではなく、**守ると§3に違反する**状態
- **さらに深刻なのは 3-9 との衝突。** 3-9が買う対象は「出荷するたびに強くなる＝複利で積み上がる会社」。
  **+100%で機械的に半分売ると、一番効く銘柄を一番早く半分にする。**
  NVIDIAもTeslaも、+100%で半分売っていたらリターンの大半を失っていた
- 一方で §2 を消すと、**OKLOの反対側（AMD/MRAM/ARMの+97,442円を放置した）の失敗**が復活する。
  このファイル冒頭に書いた設計意図そのもの

> **私の推奨**: §2を**「累積優位（3-9(3)）が無いサテライト」に限定**する。
> - **累積優位なし**（テーマ株・一過性・模倣可能）→ **+100%で半分売却**（現行どおり）
> - **累積優位あり**（AMD・NVIDIA型）→ **§3のメタトレンド評価のみ**。価格では売らない
> - ただし **-50%到達の強制再評価トリガー（§3）は両方に残す**
>
> この形なら「放置して戻した」失敗を防ぎつつ、複利を切らない。
> **AMDは累積優位あり側（設計資産・サーバ採用実績）なので、保持が正当化される。**

**✅ 2026/10/12 決着: この推奨どおり §2 を改訂した。AMD（+193.85%）は保持と判定・記録済み。**

### 🟡 矛盾② §1のサイズ枠に「売上は大きいが赤字」の区分がない ―― **決着済み**

- §1の区分は **「黒字・確立企業 4%」** と **「無収益 or 規制認証未取得 2%」** の2つだけ
- **Tesla 2019（売上$24.6B・純損失$862M）はどちらにも当てはまらない。** AMD 2015〜16も同じ
- §1の モデル層の注記「**売上があっても黒字化前は未黒字扱い**」を準用すれば **2%** だが、明記がない
- **さらに 3-8・3-9 が「上限の半分（2%以内）」と書いているため二重に曖昧**
  - 元の枠が4%なら半分は2% ／ **元が既に2%なら半分は1%（44,205円）** で、最低ポジション30,000円に近い

> **要決定**: 3-8・3-9で買う銘柄の上限は **2%（88,410円）か 1%（44,205円）か**。

> （RXRXを5,262円で持っていて「結果に影響しない」と判断して売った前例と同じ轍になる）

3-8・3-9の「上限の半分」という曖昧な表記を廃止した。**
