## 5. ルール変更（`rules.md`）

### §3 損切りルールの置き換え（米国個別株）

| | 変更前 | 変更後 |
|---|--------|--------|
| 判断軸 | 価格（-30%で半分、-50%で全売却） | **メタトレンド評価** |
| 購入時 | 損切りラインを決める | **「何が起きたら降りるか」を具体的に書く** |
| 検証 | （なし） | **四半期ごとに全銘柄を再評価** |
| 判定 | 価格のみ | テーマが死んだ→売却／**テーマは生きているが企業の位置が弱化→同テーマの別銘柄に入れ替え**／維持→保持 |
| 価格の扱い | 売却トリガー | **-50%到達は「強制再評価トリガー」**（売却義務ではなく、レビューを起動する義務） |

**なぜ価格を完全には捨てないか**: 価格ルールは雑だが「想定外のことが起きた」ことを機械的に知らせる
代替指標として働く。これを外すと「テーマはまだ生きている」を何度でも言えてしまう。
実際、OKLOは4月の-4%から9月の-56%まで一度も検証されなかった。
v3には検証可能な前提（Switch社12GW契約／DOEサイト許可／2027-28年売上開始）が書かれていたのに、読み返されなかった。

**価格を売却理由にはしないが、無視もしない。「見に行かせる」だけに使う。**
