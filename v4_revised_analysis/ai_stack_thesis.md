# AIスタック3層テーゼ — 投資方針の再定義（2026年9月）

> 発端: ユーザーの思想転換
> 「AnthropicとOpenAIも気になるが、低コスト化が気になる。それならAIを使うためのエネルギーや
>  設備系、AIを使っての製品開発（SpaceX、Waymo）が良い」

---

## 1. 結論

**この思想は正しく、かつ自己整合的。** データが裏付けている。

そして重要な発見として、**5層のうち「AIを使った製品」層は既に12.3%保有済み**だった。
唯一の穴は**エネルギー層1.53%**（しかも中身は-47.7%のOKLO 1銘柄）。

---

## 2. 「低コスト化」は事実

| 事実 | 数値 |
|------|------|
| トークン価格の下落 | 3年で**1,000倍**（99.7%減） |
| 同等能力LLMの推論コスト | 年**約10倍**のペースで低下 |
| エコノミー帯モデルの価格 | $0.10/百万トークン（6年で600倍の下落） |

## 3. ただし「だから儲からない」は誤り — ジェヴォンズのパラドックス

| 事実 | 数値 |
|------|------|
| 企業のAI支出 | 2025年に**+320%** |
| Googleのトークン処理量 | 2026年半ばで月間3.2千兆、前年比**約7倍** |
| エージェント型ワークロード | 通常のチャット1ターンの**5〜30倍**のトークン消費 |

2023年に「単一モデルへの1クエリ」だったものが、2026年には「マルチモデルのオーケストレーション」に。
**単価が1/1000になっても、使用量がそれ以上に増えれば総額は増える。**

正しい定式化は「モデル企業が儲からない」ではなく、
**「インフラ層でコモディティ化し、価値がアプリケーション層とオーケストレーション層に移る」**。
クラウドコンピューティングが辿った道と同じ。

### 思想の自己整合性

```
低コスト化が起きる → 使用量が爆発する      → 電力需要が増える      ← 「エネルギー・設備系」
低コスト化が起きる → モデル層の利幅が圧縮 → 価値がアプリ層に移る  ← 「AIを使った製品開発」
```

偶然ではなく論理的な帰結。**思想として筋が通っている。**

## 5. エネルギー層の候補評価

### 前提: 勤務先はTMEIC（東芝三菱電機産業システム）

2003年に東芝と三菱電機の折半出資で設立。2017年以降は東芝インフラシステムズ（東芝の完全子会社）が
直接の議決権を保有。**三菱電機の関係会社かつ東芝インフラシステムズの関係会社**という状態が継続。

| 候補 | TMEICとの関係 | 判定 |
|------|--------------|------|
| 三菱電機 (6503) | **親会社** | ✗ 除外（インサイダー規程の対象と推定） |
| 東芝 (6502) | **親会社**（東芝インフラシステムズ経由） | ✗ 除外（同上） |
| 安川電機 (6506) | 競合（容量帯は棲み分け） | ✗ 別の理由で除外（後述） |
| 富士電機・明電舎 | 競合 | △ 内規確認が必要 |
| 日立 (6501) | 競合だが事業の広さで希釈 | ○ 内規確認後なら可 |
| **GE Vernova (GEV)** | **親会社でも競合でもない** | **◎ 最もクリーン** |

### GE Vernova (GEV) — エネルギー層の本命

| 項目 | 実績 |
|------|------|
| Q1 2026 受注 | **$18.3B**（オーガニック **+71%**） |
| 受注残 | **$176B** |
| データセンター向け受注（電化セグメント） | Q1だけで$2.4B、2025年通年を超過 |
| ガス火力バックログ＋スロット予約 | 83GW → **100GW**、年末110GW目標 |
| ガスタービン価格 | **3年で+300%** |
| 価格改定 | 2026年受注はkW単価で前年Q4比 **+10〜20pt** |
| 生産枠 | **2029年まで満杯、2031年分まで受注** |

**OKLOとは正反対。** OKLOは売上ゼロ・NRC認証未取得だった。GEVは3年分の売上が受注残で確定している。

### 安川電機を外した理由

FY2027/2 Q1は「半導体及びデータセンター関連投資を背景にモーションコントロールが大幅増収増益、
ロボットは大幅減益」。**今の安川を動かしているのは半導体設備投資**であり、買うと
すでに15.3%あるチップ層の上乗せになる。TMEICとの距離とは無関係の理由。

### パナソニックを外した理由

MEGTRON（AIサーバ向け多層基板材料）は本物のテーマ。広州に75億円、タイ・アユタヤに170億円、
5年で生産能力2倍。**しかし売上8兆円規模のコングロマリットの中の一部門の中の一製品**であり、
20万円を投じてもMEGTRONに対応する部分はごく僅か。「落ち目」の部分を抱き合わせで買うことになる。

> **パターンの指摘**: OKLO（AI×電力・実行前の側）、4493（AI×セキュリティ・WAFレイヤー）、
> パナソニック（AIサーバ材料・巨大コングロマリット内）。
> **テーマの読みは毎回当たっている。外しているのは器の選定。** これが弱点。

## 8. 「高い」への対処についての整理

「どれもすでに高い」という懸念に対して:

- **「高い」を分解する**: (a)株価が上がった＝過去の情報、将来リターンとは無関係 /
  (b)バリュエーションが割高＝意味がある。GEVの「ガスタービン価格+300%」は**製品価格**であり、
  (a)でも(b)でもない。**むしろ価格決定力の証拠**
- **サイズが判断の重要度を決める**: 15万円のポジションが-50%になっても損失は7.5万円＝総資産の1.7%。
  **サイズを抑えることの本質は、損失を抑えることではなく、判断の正確さへの依存度を下げること**
- **枠のために買わない**: `nisa_execution_plan.md` の自己ルール
  「枠を埋めること自体を目的にしない」がここで効く。成長枠が余ってよい
- **待つなら待ち方を決める**: 「安くなったら買う」は実行されない。安くなった時は必ず怖いから
