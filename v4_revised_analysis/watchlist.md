### 1. 三菱重工 (7011) — 2027年の成長投資枠で1単元

**判断**: 買う意思は固まっている。**ただし枠と衝突しており、購入時に方式の決定が必要。**

| | |
|---|---|
| 1単元（100株） | 4,413円 × 100 = **441,300円** |
| 現在の産業・電力枠 上限5% | 210,071円（GEVが147,595円で使用中） |
| **1単元が5%枠に収まるための総資産** | **MHI単独 8,826,000円 ／ GEV+MHI 11,777,900円** |
| 現在の総資産 | 4,201,423円（**約2.8倍が必要**） |

**来年1年で到達する規模ではない。** 購入時に以下から選ぶ。

| 案 | 内容 | 評価 |
|---|------|------|
| **A** | かぶミニで枠内分だけ保有（例: 15株=66,195円 / 1.58%） | ルール維持。ただしインパクトが小さい |
| **B** | **産業・電力枠を 5% → 15% に引き上げ**（GEV+MHIで約14.0%） | `rules.md` §8の例外。**理由の記録が必要** |
| C | GEVを売ってMHIに入れ替え | 441,300円＝10.5%で、それでも5%超過 |
| D | 資産が1,178万円になるまで待つ | 現実的でない |

> **Bを選ぶ場合に書くべきこと（§8）**: なぜ5%では足りないのか／想定する最大損失額／どうなったら元に戻すのか。
> 勤務先（TMEIC）と同一マクロ要因に14%を乗せる判断になるため、収入と資産が同時に痛むシナリオを許容できるかが論点。

**推しポイント（FY2026/3 実績）**

- **受注高・事業利益・当期利益・FCF の4項目が過去最高**
- 売上 4兆9,741億円(+14.1%) / 事業利益 4,322億円(+21.8%) / 純利益 3,321億円(+35.3%)
- **エナジー**: GTCC受注 **+80% → 2兆6,526億円（過去最高）**、受注残 **5兆円超**
- **航空・防衛・宇宙**: 売上 **+38%** → 1兆3,938億円 / 事業利益 **+52%** → 1,515億円
- **原子力**: 売上 +21% → 3,611億円（国内軽水炉・燃料サイクル）
- Q1 FY2027/3: 売上+15.5% / 事業利益+65.1% / **純利益+97.4%**
- **PER 30.9倍**（GEV 27.4倍に近い。Siemens Energy 56〜63倍の約半分）

**なぜGEVと重複しないか**: 防衛と原子力は**AIデータセンターサイクルから完全に独立**した駆動要因。
ポートフォリオはAI・テック51%なので、非AI駆動の利益源には固有の価値がある。加えて**円建て**で、
ドル偏重（FANG+・米国株）の是正になる。

**確認すべきこと（購入前）**: 四半期ごとに防衛セグメントの受注・進捗、GTCC受注残の推移。

### 3. Siemens Energy — GEVの乗り換え先（条件③発動時）

**GEVの降りる条件③「Windの損失がPower/Electrificationの利益を侵食し始める」の判定基準を、
Siemens Gamesaとの比較に置く。**

| | GE Vernova | Siemens Gamesa |
|---|---|---|
| 2026通期 | **-$400M損失** | **break-even**（上方修正） |
| 直近四半期 | EBITDA損失 $275M（前年$165M）→ **拡大** | **+€56M黒字**（前年 -€425M） |
| 半期 | — | 損失€90M（前年€623M）→ **85%超改善** |
| 経営陣 | **転換点を特定できていない** | 製品簡素化・拠点最適化で計画通り |

**GEVの風力が悪化を続け、SEが黒字を定着させるなら、条件③が現実化したということ。その時の乗り換え先。**

| | GEV | Siemens Energy |
|---|---|---|
| PER | **27.4倍** | 56〜63倍 |
| 受注残 | $176B → $200B見通し | €162B ≒ $193B（記録・前年比+20%） |
| 時価総額÷受注残 | 1.32倍 | **0.83倍** |
| グリッド | Electrification マージン18.8% | Grid受注+28%、バックログ€51B記録 |

> **構図**: GEVは「今すでに稼いでいる安さ」、SEは「利益がこれから追いつく期待」。
> SEの株価は過去1年で+53.4%で、Gamesaの回復はすでに織り込まれている。
