#### 🔑 買う条件 — 価格では解決しない

```
産業・電力枠 5% = 210,071円 ／ GEVが147,595円 → 残り 62,476円
1単元(100株)が残り枠に収まる株価 = 625円（現在値から -83.8%）… 非現実的
GEV + MHI 1単元が5%に収まる総資産 = 10,685,900円（現在の約2.5倍）… 2027年には届かない
```

**「いくらで買うか」ではなく「どの枠で買うか」の問題。**

| 上限 | 枠の金額 | GEV後の残り | 1単元(386,700円) |
|------|---------|------------|-----------------|
| 5%（現行） | 210,071円 | 62,476円 | ✗ |
| 10% | 420,142円 | 272,547円 | ✗ |
| **15%** | **630,213円** | **482,618円** | **✓** |

**2027年1月に、この順で判定する**

**Step 1 — GEVの降りる条件をチェック**
- 発動していれば → **GEVを売ってMHIへ**。MHI単独は9.20%なので**上限10%**で足り、枠問題が自然に消える
- 発動していなければ → Step 2

**Step 2 — MHIの業績条件を確認（2026年11月のQ2決算で判定）**
1. GTCC受注残が5兆円超を維持
2. 防衛セグメントの受注が鈍化していない
3. 中計目標（事業利益4,500億円）の達成ペースを維持

**Step 3 — 枠をどうするか決める**

| 案 | 内容 | 評価 |
|---|------|------|
| A | かぶミニで枠内まで（現在なら16株≒62,000円 / 1.48%） | ルール維持。ただし**インパクトが薄い** |
| **B（推奨）** | **上限を15%に引き上げて1単元** | GEV+MHIで総資産の**12.7%**。§8の例外記録が必要 |
| C | GEVを売ってMHIへ（上限10%で足りる） | GEVの条件が出ていないのに売るのは churn |

> **Bを選ぶ場合に §8 へ書くこと**
> - **なぜ5%では足りないか**: 産業・電力は自分が唯一評価できる領域であり、MHIの防衛・原子力は
>   ポートフォリオの51%を占めるAI・テックと独立した唯一の利益源だから
> - **想定する最大損失**: GEV+MHIで534,295円。両方が-50%なら **-267,148円＝総資産の6.4%**
> - **どうなったら戻すか**: **勤務先（TMEIC）の業績が悪化した時**。収入と資産が同時に痛むリスクが
>   顕在化した局面で、産業枠を10%まで縮小する
>
> 最後の条件が重要。枠を広げるリスクの本質は勤務先相関なので、戻す条件もそこに紐付ける。

## 🔵 保有銘柄の整理 — チップ層の縮小（**売却候補・未実行**）

### なぜ今これを検討するか

新しく買う前に、**同じ層の中で弱い器を外す**のが順序。

```
② チップ・ハード  12.68%
  ├ FANG+経由の NVDA + MU        262,216円   ← 減らせない下限（FANG+を売らない限り）
  ├ MRAM (Everspin)               45,462円   (+82.6%)
  ├ NVDA 直接                     32,555円   (-1.15%)
  ├ AMD                           76,143円
  └ ARM                           36,884円
```

### 1銘柄ずつの判定（`rules.md` §3 メタトレンド基準）

| 銘柄 | テーマの生存 | そのテーマ内での位置 | 判定 |
|------|------------|-------------------|------|
| **MRAM (Everspin)** | 🟢 不揮発メモリは生きている | 🔴 **Moatがスケールしない**。ニッチな産業用MRAM専業で、AI推論のメモリ需要（HBM）とは別世界 | **売却候補** |
| **NVDA 直接** | 🟢 | 🟡 **FANG+の131,108円と完全重複**。直接保有分は同じ賭けの二重計上 | **売却候補** |
| AMD | 🟢 | ○ MI系でNVDAの唯一の対抗。NVDA一極への保険として機能 | **保持** |
| ARM | 🟢 | ◎ **推論の低コスト化＝電力効率**の本丸。テーゼと最も整合 | **保持** |

```
売却候補合計 = 45,462 + 32,555 = 78,017円
チップ層 12.68% → 10.82%（-1.86pt）
```

10.82%になれば、**9-3の買う条件①（チップ層10%以下）にほぼ届く**。つまりこの整理は
「現金化」ではなく「**装置層に入る扉を開けるかどうか**」の話。
