## 4. 【重大】OKLO -47.73%（-60,691円）— 原因は特定済み

### 事実

| 時点 | 評価額 | 損益率 |
|------|--------|--------|
| 4月28日 | 122,060円 | -4.0% |
| 8月18日 | **66,456円** | **-47.73%** |

取得原価は127,147円で4月と完全に一致 → **買い増しも売却もせず、株価が-45.6%下落しただけ**です。

### 下落の原因（調査結果）

1. **DOEが$17.5Bの融資プログラムを発表、対象が大型従来炉だった** → SMRセクター全体が売られた（6月に-22%）
2. **NRC（原子力規制委員会）の設計認証をまだ取得していない** — 事業化の最重要関門が未通過
3. **相場のテーマが「AI期待」から「実行の証明」へ転換** — 無収益のSMR銘柄が一斉に売られた（OKLO/XE/SMR/NNE/UEC が同時安）
4. ピーク（2025年10月 約$175）からは **-77%**、2026年通年で -41%

### 評価：テーマは壊れていない。壊れたのは時間軸の想定です。

「AIデータセンターに電力が要る」という前提自体は生きています。壊れたのは「**Okloがその電力を供給する最初の一社になる**」という部分の確度と時期です。NRC認証未取得の無収益企業に対して、市場が要求する時間軸が厳しくなりました。

**ただし本当の失敗は、株価ではなく設計にあります。** v3の時点でOKLOは122,060円＝ポートフォリオの4%でした。**無収益・規制認証未取得の単一銘柄に4%は大きすぎます。** そして損切りラインを決めないまま「保持」と結論づけたため、-48%まで見届ける結果になりました。

## 5. 個別銘柄の再評価（エンジニア視点）

### CBRS セレブラス — 設計思想は美しいが、事業構造が美しくない

**技術**: ウェハスケール・エンジン。「チップを切り出さない」という発想でGPUのメモリ帯域ボトルネックを回避する。設計思想としては極めてエレガントで、中嶋氏的な評価軸では高得点です。

**しかし2026年Q2決算で事業構造の問題が出ました:**

| 項目 | 内容 |
|------|------|
| Q2売上 | $180M（予想$194Mを未達） |
| 調整後EPS | -$0.05（予想-$0.17より良い） |
| 通期ガイダンス | コア売上 $880-890M へ上方修正 |
| 株価 | $234.85（IPO後ピーク$350から-33%）、決算後に時間外で-14% |
| **顧客集中** | **上位2社で74%**（63% + 11%）。OpenAI依存が50%超の可能性 |
| **粗利率悪化の理由** | **需要に応えるためG42（＝自社顧客）の高価な計算資源を一時的にリースしている** |

最後の行が構造的な問題です。**自社の顧客からコンピュートを借りて、別の顧客に売っている。** これはプラットフォームの経済ではなく、受託・再販に近い。参入障壁（Moat）を持つ側の振る舞いではありません。加えて売上の過半がOpenAI1社に依存しているなら、価格決定権は顧客側にあります。

**判定: 保持。ただし増やさない。** 70,411円（2.3%）は妥当なサイズです。技術の美しさと事業の美しさは別物、という典型例として持っておく価値はあります。

### 勝ち銘柄3つ — 利確ルールがないまま放置

| 銘柄 | 評価額 | 損益率 | 4月からの上昇 | コメント |
|------|--------|--------|---------------|----------|
| AMD | 76,636円 | **+136.05%** | +57% | MI系がAI推論で採用進む。本命性あり |
| MRAM エバースピン | 57,211円 | **+129.79%** | +42% | §下記 |
| ARM | 40,464円 | **+107.43%** | +24% | エッジAI基盤。v3評価◎を維持 |

**MRAMだけ性質が違います。** 不揮発性メモリ（MRAM）の技術自体は本物で、放射線耐性・書き換え耐久性で明確な優位があり、ユーザーの専門領域（産業用制御・パワエレ）とも相性が良い。**ですが市場規模が小さく、Moatがスケールしません。** 「良い技術を持つニッチ企業」であって「プラットフォーム」ではない。+130%は技術の勝利というよりテーマ買いの結果と見るべきです。**利確候補の筆頭。**

## 7. 提案するアクション（優先度順）

### 優先度1：現金を200,000円まで再建する（10月までに）

売却して現金を作る候補です。**すべて含み益銘柄なので、損切りの痛みはありません。**

| 銘柄 | アクション | 捻出額 | 理由 |
|------|-----------|--------|------|
| MRAM | **全売却** | 57,211円 | +130%。技術は本物だが市場規模が小さくMoatがスケールしない |
| AMD | **半分売却** | 38,318円 | +136%。原資回収して残り半分を無コスト化 |
| RXRX | 全売却 | 4,730円 | 4,730円では結果に影響しない |

| USルネサンス | 全売却 | 5,649円 | 端株 |
| **合計** | | **約122,912円** | |

これに **FANG+と全世界の積立を2ヶ月停止**すれば、200,000円に届きます。

### 優先度2：FANG+は「売らずに薄める」

44.5% → 30%に戻すには約440,000円の売却が必要ですが、**売却は推奨しません。**

理由: NISA口座で保有している場合、売却すると非課税枠を消費します（枠は翌年復活しますが、その年の再投資余地が減ります）。含み益+235,932円が乗っているので、特定口座なら約48,000円の税負担も発生します。

**代わりに、今後の新規資金をFANG+に一切入れない。** 積立設定があれば停止し、全世界株式とゴールドに振り替えてください。資産全体が成長するにつれ、FANG+の比率は自然に下がります。時間はかかりますが、税務コストゼロで同じ目的を達成できます。

> **要確認**: FANG+と全世界のNISA/特定口座の内訳、およびNISA成長投資枠の残額を教えてください。ここが分かると売却提案の精度が上がります。

### 優先度3：OKLOに期限を設定する

現在66,456円＝2.2%。**サイズはすでに許容範囲まで縮んでいるので、慌てて全部売る必要はありません。**

提案する条件付き保有:

- **保有継続の条件**: NRCの設計認証プロセスが前進していること（審査受理・スケジュール公表など）
- **全売却の条件**: **2027年3月末までにNRC設計認証の見通しが立たない場合**、または大規模な希薄化増資が行われた場合
- 判断を感情ではなくカレンダーに紐付けます

### 優先度4：売買ルールを明文化する（これが根本対策）

今回の分析で見えた本質は、銘柄選択ではなく**ルールの不在**です。OKLOの-60,691円もAMD/MRAM/ARMの+97,442円も、どちらも「決めていないから動かなかった」結果です。

以下を `v4_revised_analysis/rules.md` として固定することを提案します:

| ルール | 内容 |
|--------|------|
| **ポジション上限** | 無収益・未認証企業は1銘柄あたり **2%** まで（OKLOは4月時点で4%だった） |
| **利確** | サテライト銘柄が **+100%** に達したら半分売却し、原資を回収する |
| **損切り** | **-30%** で半分売却、**-50%** で全売却。例外を作らない |
| **最低ポジション** | 1銘柄 **30,000円** 未満は持たない（判断コストに見合わない） |
| **コア/サテライト比** | サテライト合計は **20%** を上限とする（現在26.4%） |

## 10. 総評

**点数をつけるなら、実行力85点・設計60点です。**

4月に決めたことを、相場に翻弄されずにほぼ全部やり切っています。特にSpaceX IPOで「初日に買わない、1〜2週間待つ」というルールを守った点は評価できます。実際SPCXは7月に$135のIPO価格を割り込んでおり、初日に飛びついていたらマイナスでした。今+4.23%なのは運ではなくルールの成果です。

問題は、**実行の途中で優先順位が入れ替わったことに気づく仕組みがなかった**点です。全世界450K・FANG+300Kという配分は、意図的に「守りを先に厚くする」設計でした。それが実際にはFANG+465K・全世界320Kになり、さらにIPOリザーブ400Kが他の銘柄に流用された。一つ一つの購入判断は悪くないのに、合計するとバーベル戦略が崩れています。

これは意志が弱いからではなく、**上がっている資産に資金が吸い寄せられるという構造的な力**が働くからです。だからこそ§7の優先度4（ルールの明文化）が効きます。制御工学的に言えば、いま足りないのは**フィードバックループ**です。目標値（ターゲット配分）はあるのに、偏差を検出して補正をかける機構がない。結果として系がオープンループで走り、たまたま入力（相場）が良かったので出力は+12.2%になっていますが、外乱が入ったときに戻す力がありません。
