## 1. テーマの判定：正しい

### 市場データ

| 市場 | 規模 | CAGR |
|------|------|------|
| AIエージェント・セキュリティ | $450M (2025) → $12.8B (2034) | **49.2%** |
| エージェンティックAIセキュリティ | $1.65B (2026) → $13.52B (2032) | **42.0%** |
| OTセキュリティ | $27.39B (2026) → $58.94B (2031) | 16.6% |
| ICSセキュリティ | $17.91B (2026) → $38.48B (2031) | 16.5% |

AIエージェント・セキュリティ関連スタートアップへのVC投資は2024〜2025年の2年で **$1.2B超**。

### なぜ構造的に正しいか（2つのメカニズム）

**(1) 攻撃コストの非対称な低下**
LLMによってフィッシング、脆弱性発見、ソーシャルエンジニアリングのコストが下がる。**攻撃側のコストは防御側のコストより速く下がる**（攻撃は自動化と相性が良く、防御は文脈判断を要するため）。これだけでもセキュリティ支出は増えます。

**(2) 新しい攻撃面の出現** ← こちらが本質

- プロンプトインジェクション
- エージェントの乗っ取り・権限昇格
- ツール呼び出しの悪用
- モデルのサプライチェーン
- **非人間アイデンティティ**（エージェントが保持する認証情報）

これらは3年前に存在しなかったカテゴリです。**「既存のセキュリティ予算が増える」のではなく「新しいレイヤーが出現して、そこに新しいスタックが必要になる」。** これはメタトレンドの定義そのものです。中嶋氏の評価軸に照らしても、パラダイムシフトの条件を満たしています。

CrowdStrikeが実際にここへ動いています。Falconプラットフォームをアイデンティティ、ブラウザ、AI固有の制御へ拡張し、**エージェンティック・ワークフローと非人間アイデンティティ保護**を新しい制御面として位置づけています。

**確信は妥当です。テーマ認識としては正しい。**

## 2. 【重要】FANG+ が2026年3月にCRWDを除外していた

**2026年3月の定期入替で、FANG+指数は CrowdStrike (CRWD) を除外し、マイクロン・テクノロジー (MU) を採用しました。**

これは今回の話の核心に関わります。

| | 3月入替前 | 3月入替後 |
|---|---|---|
| CRWD経由のサイバーセキュリティ | 約135,293円（総資産の3.11%） | **0円（0.00%）** |
| 代わりに MU（メモリ/HBM） | 0円 | 約135,293円（3.11%） |

つまり:

1. **3月以前は、FANG+経由でCrowdStrikeを実質3.11%保有していた。** それが機械的な入替でゼロになった
2. **現在のサイバーセキュリティ保有は 4493 の1.32%のみ。** 3月以前より薄い
3. **「AIセキュリティの波」への備えは、意図せず後退していた**

**4493を買った判断は、偶然にもこの穴を埋めるものでした。** テーマ認識が正しかっただけでなく、タイミングとしても理にかなっています。ここは率直に評価すべき点です。

### 副作用：半導体集中度が上がった

セキュリティ銘柄がメモリ半導体に置き換わったため、ポートフォリオ全体の半導体依存が増しました。

| 経路 | 金額 |
|------|------|
| FANG+ NVDA | 135,293円 |
| **FANG+ MU（3月に追加）** | **135,293円** |
| 直接 NVDA / AMD / ARM / CBRS / MRAM | 279,772円 |
| EWY（サムスン・SKハイニックス、概算） | 28,000円 |
| 全世界経由の半導体（概算） | 54,630円 |
| **合計** | **約 632,989円 = 総資産の 14.5%** |

うち **メモリ/HBM系統（MU + EWY）が3.7%**。EWYを買った時点でサムスン・SKハイニックスを持っているところに、FANG+側でもマイクロンが乗った形です。**HBMという同一の賭けが二重になっています。**

これは前回指摘した「全世界株式へ275,612円を投入する」提案（優先度1）の根拠をさらに強めます。

## 3. 4493 という会社の評価

### 財務：健全。テーマ株ではなく、ちゃんと儲かっている会社

| 項目 | 2026年12月期 中間期 | 前年同期比 |
|------|---------------------|-----------|
| 売上高 | 27億7,100万円 | +14.6% |
| 営業利益 | 6億2,000万円 | **+30.0%** |
| 純利益 | 4億5,000万円 | **+43.7%** |
| 通期予想 | 売上60億円 / 純利益8億6,500万円 | 据え置き・**増配予定** |

- **営業利益率 22.4%** — SaaSとして健全な水準
- 売上+14.6%に対して営業利益+30.0% → **オペレーティングレバレッジが効いている**
- 株価 1,981円（2026年8月14日）、東証グロース

**赤字のテーマ株ではありません。** OKLOやRXRXとは性質がまったく違い、この点は重要です。

### 設計思想：合理的（CBRSと対照的）

主力2製品:

| 製品 | 内容 |
|------|------|
| **攻撃遮断くん** | クラウド型WAF。DNS切替型とエージェント連動型。**国内シェアNo.1** |
| **WafCharm** | AIとビッグデータで **AWS WAF / Azure WAF / Google Cloud Armor を自動運用**。90以上の国と地域、3,000以上のユーザー |

WafCharmの位置取りが巧いところです:

- **ハイパースケーラーと競合していない。** AWS WAF自体を置き換えようとせず、その「運用」を引き受けている
- WAF本体がコモディティ化する（AWSが事実上ただ同然で提供する）ことを前提として受け入れた上で、価値の置き場所をずらした
- Moatは**蓄積した攻撃データ**: 顧客増 → 攻撃観測増 → ルール精度向上 → 顧客増 というデータ・フライホイール

**CBRSが「設計思想は美しいが事業構造が美しくない」だったのに対し、4493は「事業構造は美しいが規模が小さい」です。** エンジニア視点での評価は、実は4493の方が高くなります。

### 問題：テーマのβを持っていない

| | 成長率 |
|---|---|
| AIエージェント・セキュリティ市場 | CAGR **49.2%** |
| エージェンティックAIセキュリティ市場 | CAGR **42.0%** |
| CrowdStrike（売上） | +23% |
| **4493（売上）** | **+14.6%** |

**テーマは年40〜50%成長なのに、この会社は15%成長です。** テーマCAGRの約3割しか取り込めていません。

理由は明確で、**WAFはAIエージェント時代の主戦場ではない**からです。

WAFが守るのは「WebアプリケーションへのHTTP攻撃」というレイヤーです。一方、§1で挙げた新しい攻撃面 — プロンプトインジェクション、エージェントの権限昇格、ツール呼び出しの悪用、非人間アイデンティティ — は、**いずれもWAFのレイヤーの外側**にあります。

> **「AIの影響でセキュリティに波が来る」という前提は正しい。**
> **しかし、その波が立つ場所は 4493 のいる場所ではない可能性が高い。**

4493は「AIセキュリティの波の受益者」ではなく、「**既存のWebセキュリティ市場で着実にシェアを取っている良い会社**」です。この2つは別物として扱う必要があります。

## 4. 判定：趣味枠として保有継続。ただし「テーマ投資」に数えない

**保有継続に賛成します。** 理由:

1. **財務が健全** — 営業利益率22.4%、増収増益、増配予定。損失が膨らむ性質の銘柄ではない
2. **サイズが適正** — 57,630円＝総資産の**1.32%**。`rules.md`の上限（黒字・確立企業4%）に十分収まっている
3. **趣味枠には機能がある** — 自分の確信で持つポジションは、相場を継続的に見る動機になります。任天堂の趣味枠と同じ役割で、これはポートフォリオ運用上むしろプラスです

**ただし1点だけ**: これを「AIセキュリティ・テーマへのエクスポージャー」として数えないでください。分類上は「**国内小型SaaSの個別株**」です。テーマを取りたいなら別途必要になります。

## 5. テーマを本当に取りにいくなら：2つの選択肢

### 選択肢A：CRWD — 3月に開いた穴を素直に埋める

CrowdStrike FY2026 実績:

| 項目 | 実績 |
|------|------|
| Q4売上 | $1.31B（+23% YoY） |
| ARR | **$5.3B（+24%）** |
| 年間の純増ARR | **$1B超（過去最高）** |
| GAAP純利益 | **黒字化** |
| 2029年見通し | 売上$9.3B（年22%成長が前提） |

Fal.Con 2026は例年より早く完売、AWSと共同でグローバルAIセキュリティ・チャレンジを立ち上げ。**エージェンティック・ワークフローと非人間アイデンティティ保護**を明確に次の制御面と位置づけています。

**FANG+が除外したのは、指数の機械的ルール（時価総額・流動性ランキング）によるものであって、事業が悪化したからではありません。** 3月以前と同じエクスポージャーに戻したいなら、直接保有が最も素直な解です。

### 選択肢B：OT・ICSセキュリティ ← **本命はこちらだと思います**

**ここがこの分析でいちばん伝えたい部分です。あなたの情報優位が唯一存在する領域です。**

WAFやWebセキュリティにおいて、あなたは他の個人投資家に対して何の優位もありません。決算資料から読み取れる情報しか持っていない。

しかしOT（制御システム）セキュリティでは話が違います:

- PLC・インバータ・ドライブが実際の産線でどうネットワークに繋がっているかを知っている
- Modbus / EtherCAT / PROFINET / CAN が **認証の概念を持たない前提で設計されている**ことを知っている
- 「エアギャップがあるから安全」が現場では成立していないことを知っている
- **稼働中の産線にパッチを当てることが実質不可能**だと、体感として知っている

**これらは決算資料を読んでも分からない知識です。** 中嶋氏的な意味での「自分が本当に評価できる領域」は、サイバーセキュリティ全般ではなく、ここに限定されます。

市場も本物です:

- OTセキュリティ: $27.39B (2026) → $58.94B (2031)、**CAGR 16.6%**
- ICSセキュリティ: $17.91B (2026) → $38.48B (2031)、**CAGR 16.5%**
- ドライバー: IT/OTの融合、産業IoTの普及、ランサムウェアの産業設備への波及
- **Dragosが EmberAI（OTネイティブなAI機能）を投入** — 運用文脈と産業脅威インテリジェンスを組み合わせる。AIがOTセキュリティの差別化要因になり始めています

**問題は、主要プレイヤーの多くが非上場であることです。**

| ベンダー | 上場 | 特徴 |
|----------|------|------|
| **Dragos** | 非上場 | 産業脅威インテリジェンス特化。EmberAI |
| **Claroty** | 非上場 | XIoT統合。規制産業・医療・ビル設備 |
| **Nozomi Networks** | 非上場 | 多拠点のOT/IoT監視、AI分析 |
| **Tenable (TENB)** | **上場** | Indegy買収がベース。**IT+OTを単一のエクスポージャー・ビューに統合**する点が強み |
| Armis | 非上場 | |
| PANW | 上場 | OTモジュールあり（ただし全社に占める比率は小さい） |

現状、上場している中で最も純度が高いのは **TENB** ですが、本体は脆弱性管理（VM）の会社でOTは一部門なので、「純粋なOTプレイ」ではありません。

### 提案：今すぐ買わない。条件付きウォッチリストに置く

SpaceX / Anthropic と同じ枠組みで管理します。

| 対象 | トリガー | アクション |
|------|---------|-----------|
| **Nozomi Networks / Claroty / Dragos** | いずれかがIPOした場合 | `rules.md` のIPOルールを適用（**初日は買わない。上場1〜2週間後に分割購入**） |
| **TENB** | OT部門の売上が個別開示される、またはOT比率が明確に上昇した場合 | 再評価して購入判断 |
| **CRWD** | 全世界株式への投入（優先度1）が完了した後 | 3月に開いた穴を埋める目的で少額から検討 |

**優先順位としては、前回の優先度1（全世界株式へ275,612円）が先です。** 配分の穴を埋めてから、テーマの穴を埋めてください。順序を逆にすると、また4月と同じ「攻め側から先に埋まる」パターンになります。

## 6. まとめ

確信は正しく、しかも**気づかないうちに3月に開いていた穴を埋める行動**でした。そこは評価されるべきです。

ただし4493は「良い会社」であって「テーマの受け皿」ではありません。趣味枠1.32%として持ち続けるのは合理的ですが、**これでAIセキュリティに賭けたつもりにならないでください。**

そして、もしこのテーマを本気で取りにいくなら、**あなたが他人より上手く判断できるのはWebセキュリティではなくOT/ICSセキュリティです。** 現時点では上場した純粋な受け皿がないため待ちになりますが、Nozomi・Claroty・DragosのIPOは十分あり得ます。**待つ価値のある領域**だと考えます。
